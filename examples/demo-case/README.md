# 合同纠纷演示案件（完全合成）

这里的主体、合同、日期、对话和金额均为演示编写，不对应真实案件。材料故意保留缺口，用来观察 Agent 是否区分材料记载、当事人陈述与待核事项。

- 合同价款 100,000 元，演示付款记录显示已付 30,000 元。
- 双方对交付是否合格有分歧，材料中没有双方签署的验收单。
- 甲方提出另有 5,000 元费用，没有提供凭证；不得直接登记为已证实损失。
- 不附法律数据库；有效法条需要用户提供或接入检索服务后核验。

先运行 `npm run legal:setup`，再对 `.local/demo-case/材料` 预处理。请在生成的 `.local/demo-case` 中体验，以免改动仓库示例。
